# Макет сайта Пермского отделения «Деловой России»

Живой макет: https://halitcan777.github.io/deloros-perm-maket/ (закрыт от поисковиков)
Исходный сайт: https://deloros-perm.ru (1С-Битрикс + Аспро Приорити, подрядчик Amado)

Суть: структура и содержание прежние, акцент на привлечении новых членов (лидген).
Визуальный язык взят у deloros.ru (нравится заказчику): белый, синий #2563eb, серые подложки.
Шрифт Onest вместо платного RF Tone.

## Как устроено

```
tools/mirror.py      полная копия deloros-perm.ru → _сырьё/mirror (≈10 ГБ, ≈3000 страниц + файлы)
tools/fetch_news_lists.py  списки новостей по годам (в них даты публикаций)
tools/extract.py     копия → data/*.json (новости, мероприятия, люди, проекты, комитеты, клубы, советы, партнеры, страницы)
src/build.py         data → site/ (≈850 страниц, картинки в WebP)
src/assets/          site.css, app.js, шрифты, логотип
deploy.sh            сборка под GitHub Pages → docs/ → push
```

Локально: `python3 src/build.py && cd site && python3 -m http.server 8765`.
`_сырьё/`, `data/`, `site/` в репозиторий не входят, пересоздаются скриптами.

В макете полные страницы есть у новостей с 01.10.2025 и мероприятий с 01.09.2025,
более старые карточки ведут на текущий сайт. При переезде переносится весь архив (данные уже извлечены).

## Новая структура меню

Сообщество · Участники · Возможности · Проекты · Мероприятия · Новости · Контакты · [Вступить]

- «Книга» убрана из первого пункта меню, ссылка в подвале и в проектах.
- В «Проектах» 6 приоритетных + «Все проекты».
- Служебное (документы, реквизиты, политика) в подвале и в разделе «Сообщество».

## Главная (под привлечение)

Первый экран: кто мы, кого объединяем, «Обсудить вступление» и «Посмотреть участников», ближайшее событие.
Ниже: ближайшие мероприятия (с заглушкой «Скоро появится», когда анонсов нет) → что получает участник →
кому подходит → отделение в цифрах (с периодом у каждой цифры) → проекты → новости → руководство →
5 шагов вступления → короткая заявка.

## Предложения ЕН (15 пунктов) — что сделано и что ждет данных

5 (меню), 6 (страница вступления: кому, условия, взносы, этапы, документы, FAQ), 7 (одна короткая заявка + «что дальше»),
8 (таблица пакетов, «Премиум» переписан без саун, кальян-баров, самолетов и «элит»), 9 (действующие/архив, команда проекта из карточек),
10 (фильтры участников, «Предложить сотрудничество» вместо открытых почт, почты вычищены из всех текстов), 11 (ближайшие/прошедшие, открытые/для участников, регистрация).

- 9: статусы проектов (сейчас по году и номеру проекта), руководители проектов;
- 10: отрасль, компетенции, потребности участников (для фильтров по отраслям);
- 12: отчеты 2024–2025, презентация 2026;
- 13: в какой портал Битрикс24 слать заявки (форма уже собирает имя, компанию, должность, телефон, интерес, источник);
- 14: Метрика (цели в app.js размечены), домены, бэкапы — при запуске;
- 15: страницы под аудитории — после основных правок.

## Форма заявки

В макете ничего не отправляет, показывает экран «что дальше». На проде: обработчик на сайте → лид в Битрикс24.
