# Макет сайта Пермского отделения «Деловой России»

Живой макет: https://halitcan777.github.io/deloros-perm-maket/ (закрыт от поисковиков)
Исходный сайт: https://deloros-perm.ru (1С-Битрикс + Аспро Приорити, подрядчик Amado)

Суть: структура и содержание прежние, акцент на привлечении новых членов (лидген).
Визуальный язык взят у deloros.ru (нравится заказчику): белый, синий #2563eb, серые подложки.
Шрифт Onest вместо платного RF Tone.

## Как устроено

```
tools/mirror.py      полная копия deloros-perm.ru → _сырьё/mirror (≈10 ГБ, ≈3000 страниц + файлы)
tools/fetch_news_lists.py  списки новостей по годам (в них даты публикаций)
tools/extract.py     копия → data/*.json (новости, мероприятия, люди, проекты, комитеты, клубы, советы, партнеры, страницы)
src/build.py         data → site/ (≈850 страниц, картинки в WebP)
src/assets/          site.css, app.js, шрифты, логотип
deploy.sh            сборка под GitHub Pages → docs/ → push
```

Локально: `python3 src/build.py && cd site && python3 -m http.server 8765`.
`_сырьё/`, `data/`, `site/` в репозиторий не входят, пересоздаются скриптами.

В макете полные страницы есть у новостей с 01.10.2025 и мероприятий с 01.09.2025,
более старые карточки ведут на текущий сайт. При переезде переносится весь архив (данные уже извлечены).

## Структура (v2, 16.10): схема блоков deloros.ru, тексты только с deloros-perm.ru

Владелец забраковал v1 как ИИ-слоп. В v2 убраны все придуманные блоки и тексты («Что получает участник»,
«Кому подходит», цифры, 5 шагов, синие формы на каждой странице). Схема блоков снята с deloros.ru, код свой.

- Шапка в две строки: «Вступить в организацию», соцсети, «Оплатить взнос», «Книга», телефон, поиск / логотип + меню.
- Меню: О нас · Лица · Комитеты · Советы · Клубы · Проекты · Возможности · Мероприятия · Пресс-центр · Контакты.
- Главная, порядок как у deloros.ru: баннер → Новости (крупная + 6 карточек) → Анонсы → Слово председателя →
  Пресс-центр с вкладками → Направления → Полезное → Наши партнёры → синий подвал.
- Внутренние: голубая полоса с крошками, заголовок, контент слева, справа виджеты «Новости»/«Анонсы» или меню раздела.
- Списки строками (новости с поиском и датами, мероприятия с красной датой у ближайших), комитеты/клубы/советы строками с руководителем,
  проекты и возможности плитками, «Лица» блоками по группам.
- Вступление в 3 шага, как у deloros.ru: информация о членстве (текст отделения) → пакеты (100 000 / 190 000 ₽) → личная информация.

На сайте отделения на самом деле 6 комитетов, 11 клубов, 20 советов и рабочих групп (в v1 считалось неверно, туда попадали пункты меню).

**Новая нелепость на живом сайте:** на 5 из 6 страниц комитетов вместо кнопки «Вступить в комитет» выводится служебный
дамп Битрикса («Array ( [ID] => … [TIMESTAMP_X] => …»), например deloros-perm.ru/commissions/industry/. В макете вырезан.
