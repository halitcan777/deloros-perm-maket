Оборин Алексей Владимирович

Директор ООО «Ионные Технологии»

ООО "Ионные Технологии" - это промышленный инжиниринг, разработка технологий белой металлургии, изготовление оборудования для механической и химико-термической обработки металлов, проведение НИОКР, обучение инженерно-технического персонала.

ООО "Ионные Технологии" обеспечивают надежные поставки широкого ассортимента деталей и оборудования для промышленных трубопроводов, трубопроводов высокого давления, трубопроводов агрессивных и высокотемпературных сред.

Ионное азотирование деталей - выполнение работы по упрочнению изделий из сталей и сплавов на собственных ионных установках. Полный комплекс НИОКР, передовые технологии, мировой уровень.

Ключевые компетенции:

  • опыт создания инновационных образцов техники из металлов и сплавов, во всех отраслях промышленности;
  • создание производственных цепочек-взаимосвязей по выпуску продукции машиностроения, в т.ч. двойного назначения.

Хобби и увлечения:

  • чтение книг по экономике, инновациям, технологиям металлургии и машиностроения;
  • спорт - беговые лыжи, велосипед по пересечённой местности.
