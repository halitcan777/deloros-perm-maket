Задачи комитета

  1. Обобщение региональной практики налогообложения
  2. Экспертиза налоговых вопросов, федерального и регионального законодательства
  3. Проведение мероприятий (налоговый форум, вебинары, встречи с ФНС)
  4. Решение кейсов членов ДР в сфере налогообложения

Основные проблемы, на которые направлено внимание комитета, и предложения по их решению

  1. Облегчение налогового режима в регионе: выработка предложений для Законодательного собрания и Правительства Пермского края
  2. Влияние на формирование правового пространства по спорным вопросам в области налогообложения: изучение острых налоговых вопросов в регионе
  3. Формирование площадок для обсуждения налогообложения: форумы, круглые столы, вебинары
  4. Экспертиза конкретных вопросов налогообложения: формирование экспертных заключений
  5. Налоговое прогнозирование: совершенствование алгоритма влияния налогообложения на экономику региона
