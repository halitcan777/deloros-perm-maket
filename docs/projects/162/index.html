Форум-группа «Совет директоров»

Статус
Действует
Как присоединиться
Оставить заявку ниже, дирекция свяжет с руководителем проекта

Совет директоров – это закрытая стратегическая группа из 8-10 предпринимателей, объединенных принципом: «Сильные растут в окружении сильных». Это пространство, где руководители могут обсуждать реальные бизнес-и личные задачи, получать поддержку, решения и вдохновение.

В основе проекта — доверие, конфиденциальность и принцип «равные помогают равным». Здесь нет экспертов, которые рассказывают, как правильно вести бизнес. За одним столом собираются практики, которые сами каждый день принимают решения, отвечают за команды, деньги и развитие компаний.

Форум-группа объединяет владельцев и топ-менеджеров, имеющих сопоставимый деловой опыт, но обязательно из разных сфер – во избежание конфликтных ситуаций и соперничества.
Цели форум-группы:

1. Повысить эффективность бизнеса участников через коллективный интеллект группы.

2. Дать каждому участнику безопасное пространство для анализа своих управленческих решений.

3. Создать среду, где можно говорить не только о росте и деньгах, но и о человеческой стороне лидерства: усталости, выгорании, семье, смысле.

4. Выстроить сильное сообщество предпринимателей, способных влиять на регион и страну.

Каждый участник работает по принципу:

Я прихожу → формулирую запрос → получаю альтернативы мышления → принимаю решение → возвращаюсь с результатом → корректирую курс.

Хотите стать участником следующей группы «Совета директоров»?

Заполните анкету, чтобы рассказать о себе, своём бизнесе и задачах, с которыми вы хотели бы работать в рамках проекта → заполнить анкету.

Модератор проекта — Милана Кулакова.
