Клуб частного инвестора «Деловой России»

Статус
Действует
Как присоединиться
Оставить заявку ниже, дирекция свяжет с руководителем проекта

«Клуб частного инвестора» — проект объединяющий участников, заинтересованных в частных инвестициях и финансовых рынках. В рамках проекта проводятся встречи, посвященные анализу текущей ситуации на финансовых рынках, обсуждению инвестиционных инструментов, рыночных тенденций, возможных сценариев и рисков.

Цели и задачи проекта:


Цель проекта — создание постоянно действующей площадки для обмена инвестиционным опытом, получения актуальной аналитической информации и обсуждения ситуации на финансовых рынках.

• Проведение регулярных встреч по актуальным вопросам финансовых рынков.
• Анализ ситуации по основным инвестиционным инструментам и факторов, влияющих на их динамику.
• Рассмотрение возможных сценариев развития рынка и связанных с ними рисков.
• Обсуждение подходов к управлению инвестиционными рисками.
• Обмен практическим опытом между участниками.
• Предоставление участникам актуальной аналитической информации между встречами.
• Повышение уровня знаний участников в сфере частного инвестирования.
Для взаимодействия между встречами действует закрытый чат Клуба, в котором размещаются актуальная аналитика, оперативные комментарии по ситуации на рынке и анонсы мероприятий.

Куратор проекта — Анна Волегова.
